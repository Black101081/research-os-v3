# Factor Thesis Library v1

Purpose: define factor-level theses so raw measurements are treated as disciplined research objects rather than loose feature lists.

## Thesis schema
- thesis_id
- factor_family
- measurement_scope
- core_question
- intuition
- information_edge
- non_edge_warning
- preferred_regimes
- avoid_regimes
- signal_roles
- strategy_roles
- misuse_patterns
- failure_archetypes
- validation_targets

## Family theses

### Return and displacement
- Core question: How far, how fast, and how abnormally price has moved relative to recent equilibrium.
- Information edge: useful as a baseline layer for stretch, drift, and transition detection.
- Non-edge warning: raw displacement is usually control information, not differentiated alpha.
- Misuse patterns: fading every extreme; mistaking fast movement for confirmed breakout.
- Validation targets: stretch persistence, recenter efficiency, impulse contamination.

### Trend structure
- Core question: Is directional path coherent enough to support continuation or renewal?
- Information edge: useful for separating healthy path structure from late or fragile continuation.
- Non-edge warning: simple trend alignment is a benchmark, not proof of edge.
- Misuse patterns: trusting crossover-style persistence without damage checks.
- Validation targets: coherence retention, late-entry penalty, fragility frequency.

### Participation and activity
- Core question: Is participation confirming, weakening, or contradicting price motion?
- Information edge: useful for breakout confirmation and effort-versus-result interpretation.
- Non-edge warning: high activity is not automatically conviction.
- Misuse patterns: treating all volume spikes as confirmation.
- Validation targets: participation asymmetry, follow-through quality, burst contamination.

### Volatility and compression
- Core question: Is volatility storing pressure, releasing cleanly, or exhausting?
- Information edge: useful for separating orderly transition from noise.
- Non-edge warning: compression is not direction and expansion is not always fresh opportunity.
- Misuse patterns: trading every squeeze, fading every expansion.
- Validation targets: orderly release rate, false breakout rate, expansion decay quality.

### Microstructure and execution
- Core question: Is the setup realistically tradeable under current tape and liquidity conditions?
- Information edge: useful as a tradeability gate and hazard detector.
- Non-edge warning: execution context is usually a veto layer, not directional alpha.
- Misuse patterns: promoting execution filters as standalone alpha.
- Validation targets: bad-trade reduction, slippage avoidance, liquidity trap precision.

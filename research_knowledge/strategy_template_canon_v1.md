# Strategy Template Canon v1

Purpose: standardize strategy family descriptions so every strategy is evaluated as a falsifiable, baseline-beating research object.

## Required template fields
- strategy_family
- parent_signal_families
- baseline_controls
- differentiated_claim
- why_now_logic
- validation_focus
- risk_focus
- execution_realism_assumptions
- promotion_rule
- rejection_rule
- failure_archetypes
- negative_knowledge_targets
- validation_targets
- lifecycle_requirements
- validator_checks

## Canon rules
- Every strategy must state which baseline it is trying to beat.
- Every strategy must state why the edge should exist now, not just in theory.
- Every strategy must include at least one explicit rejection rule.
- Every strategy must define execution realism assumptions, not only alpha logic.
- Every strategy must identify how negative evidence should be stored and reused.
